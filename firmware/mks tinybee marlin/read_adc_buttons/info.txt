===========================================================
  ИНСТРУКЦИЯ: Измерение ADC значений кнопок ZONESTAR LCD
           для MKS TinyBee (ESP32)
===========================================================

ПРОБЛЕМА:
Кнопки UP, DOWN, LEFT, RIGHT, ENTER не работают, хотя
кнопка MENU (BTN_ENC = IO13) работает правильно.
Это связано с тем, что ZONESTAR LCD использует ADC-кнопки
через пин IO35, и текущие пороги могут не соответствовать
вашему дисплею.

ВАЖНО: ESP32 имеет 12-битный АЦП (0-4095), но Marlin
масштабирует значения до 10 бит (0-1023). Тестовый скетч
показывает оба значения. Для настройки прошивки используйте
10-битные значения (колонка "10-bit scaled").

ЧТО НУЖНО СДЕЛАТЬ:
Измерить реальные ADC значения при нажатии каждой кнопки.

-----------------------------------------------------------
ШАГ 1: Скопировать папку read_adc_buttons на реальный ПК
-----------------------------------------------------------
Папка содержит:
  - read_adc_buttons.ino  (скетч для чтения ADC)
  - platformio.ini        (конфигурация PlatformIO)
  - info.txt              (этот файл)

-----------------------------------------------------------
ШАГ 2: Собрать и загрузить тестовый скетч
-----------------------------------------------------------
Откройте терминал в папке read_adc_buttons и выполните:

  pio run --target upload -e mks_tinybee_test

Если нужно указать порт вручную (на Windows это COM3 и т.д.):

  pio run --target upload -e mks_tinybee_test --upload-port COM3

-----------------------------------------------------------
ШАГ 3: Открыть монитор порта
-----------------------------------------------------------
После загрузки выполните:

  pio device monitor

Или с указанием порта:

  pio device monitor --port COM3

-----------------------------------------------------------
ШАГ 4: Нажать каждую кнопку и записать ADC значения
-----------------------------------------------------------
В мониторе порта будут отображаться значения:
  RAW (12-bit) | 10-bit scaled | Voltage

Нажимайте по очереди каждую кнопку и записывайте значения
из колонки "10-bit scaled" (они используются в прошивке):

  Кнопка         | RAW (12-bit) | 10-bit scaled
  ----------------|--------------|---------------
  Нет нажатия    | ____________ | ____________
  UP (Вверх)     | ____________ | ____________
  DOWN (Вниз)    | ____________ | ____________
  LEFT (Влево)   | ____________ | ____________
  RIGHT (Вправо) | ____________ | ____________
  ENTER (Центр)  | ____________ | ____________

-----------------------------------------------------------
ШАГ 5: Отправить значения разработчику
-----------------------------------------------------------
После того как запишете все значения, отправьте их
разработчику для настройки правильных порогов ADC
в файле pins_MKS_TINYBEE.h.

===========================================================
  ДОПОЛНИТЕЛЬНЫЕ КОМАНДЫ
===========================================================

Сборка основной прошивки Marlin (без загрузки):
  (из корневой папки проекта)
  pio run -e mks_tinybee

Сборка + загрузка основной прошивки:
  pio run --target upload -e mks_tinybee

Сборка + загрузка с указанием порта:
  pio run --target upload -e mks_tinybee --upload-port COM3
